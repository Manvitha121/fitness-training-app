# Fitness Training App

A clean, responsive fitness tracking app built with React and Vite.

Features:
- Daily activity dashboard
- Step tracking
- Calories burned tracking
- Active minutes and hydration tracking
- Workout logging
- Weekly progress chart
- Local browser storage
- Terms & Conditions acceptance flow

## Run locally

1. Install dependencies:
   npm install
2. Start the app:
   npm run dev
3. Build for production:
   npm run build

## Project structure

- `src/App.tsx` – main app logic and UI
- `src/styles.css` – styling and layout
- `src/main.tsx` – app entry point
